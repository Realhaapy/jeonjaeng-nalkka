이 서비스가 하는 일표시의 의미자료와 확인 범위갱신과 지연정정과 운영

많은 보도보다 중요한 것은 변화입니다.

‘전쟁 날까’는 한반도 군사 뉴스에서 새로 확인된 사실, 이전과 달라진 내용, 공식 발표·조치와 미확인 사항을 정리합니다. 기사 여러 개가 같은 발표를 반복하는지, 새로운 행동이 있었는지를 구분합니다.

우리는 전쟁이 일어날 확률을 계산하지 않습니다. 사건 기록이 적거나 새 발표가 없다는 이유로 안전하다고 판단하지 않습니다. 긴급한 행동은 국민재난안전포털의 공식 안내 를 확인해 주세요.

‘발표 확인’과 ‘독립 확인’은 다릅니다.

발표 확인
특정 기관이나 매체가 그 내용을 발표했다는 것을 확인했습니다. 발표 내용 전체가 독립 검증됐다는 뜻은 아닙니다.
추가 근거 확인
같은 주장을 뒷받침하는 서로 독립된 근거를 검토했습니다. 사건 발생과 피해 규모는 각각 확인합니다.
내용 상충
자료가 서로 다른 주장을 합니다. 어떤 부분이 다른지와 근거를 함께 남깁니다.
철회된 기록
잘못된 내용이나 중복 등으로 현재 사건 목록에서 제외해야 하는 기록입니다. 바뀐 이유를 보존합니다.

‘종료 미확인’은 진행 중이라는 확정도, 끝났다는 판단도 아닙니다. 중요한 사건은 종료 근거를 확인할 때까지 계속 표시합니다.

출처를 읽고, 근거를 연결합니다.

이용조건을 확인한 무료 공식 자료를 우선합니다. 현재는 공식 자료를 중심으로 같은 문서 주소와 내용의 중복을 제거합니다. 서로 다른 기사 사이의 재전송 관계는 자동 확정하지 않고 검토합니다. 서로 다른 기관의 발표도 같은 관측 정보를 인용했다면 독립 근거로 자동 계산하지 않습니다.

문서에서 사건·시각·주장을 추출할 때 AI가 보조할 수 있습니다. 숫자와 표시 상태는 정해진 규칙으로 계산하고, 근거가 맞지 않거나 중요한 미확인 주장은 검토를 거칩니다. AI의 확신을 사실 확인으로 사용하지 않습니다.

영국 외무부 한국 여행정보GOV.UK 공개 API·OGL 자료. 제3자 권리가 있는 자료는 제외. 여행정보는 군사 경보와 다릅니다.대한민국 정책브리핑공개 목록의 제목·출처 링크만 발견합니다. 개별 공공누리 표식 확인 전 본문 수집·AI 요약은 보류합니다.일본 방위성 통합막료감부공개 영문 목록의 한반도 관련 링크만 발견합니다. 이용조건 확인 전 PDF 본문 수집·AI 요약은 보류합니다.주한미군 공식 발표 · DVIDSUSFK 공식 페이지가 제공하는 공개 RSS의 원제목·링크·게시일만 수집합니다. DVIDS 저작권 안내는 제3자 권리와 비보증을 명시하므로 본문·이미지·AI 요약은 사용하지 않습니다. 미국 정부의 보증·후원을 뜻하지 않습니다.BBC News Asia · 수집 보류RSS 접근은 확인했으나 BBC 개인 이용 조건의 피드 변경 금지·메타데이터 추출 제한 때문에 현재 선별 저장 방식은 비활성화했습니다. 허용되는 피드 표시 방식 또는 별도 이용 허락 확인 후 연결합니다.

원문 전체를 복제하지 않고 필요한 짧은 설명과 출처 링크를 제공합니다. ‘자료원 2/3 확인’은 점검한 범위이며 사건의 진실 확률이나 안전 점수가 아닙니다.

기사 시각과 자료 확인 시각을 구분합니다.

발생 시각은 실제 사건이 일어난 때, 게시 시각은 문서가 올라온 때입니다. 발생 시각을 모르면 기사 시각으로 대신 채우지 않습니다. 자료 확인 시각은 지정한 자료원을 정상 점검한 범위를 나타냅니다.

자동 실행을 설정하면 매시간 수집을 시도합니다. 현재 갱신 상태는 표시된 자료 확인 시각을 참고하세요. 종료·절전·통신 장애가 있으면 새 정보 반영이 멈출 수 있습니다. 확인 범위가 2시간 넘게 지나면 지연, 6시간이 넘으면 오래된 자료로 안내합니다.

공유한 브리핑은 그때의 기록입니다. 이후 정정이 있어도 예전 화면만 돌 수 있으므로 최신 페이지와 정정 기록을 연결합니다. 새 자료가 없다는 이유로 위험이 낮아졌다고 설명하지 않습니다.

틀린 내용은 이유와 함께 고칩니다.

추가 확인·정정·철회는 원래 사건에 연결하고 변경 시각과 이유를 남깁니다. 기준이 바뀌어 생긴 변화는 실제 사건의 변화와 구분합니다. 현재 방법론 버전은 1.0입니다.

이 MVP는 시험 운영 단계입니다. 정확도·장기간 갱신 안정성과 이용자 이해도 검증이 완료됐다고 주장하지 않습니다. 운영 계정은 GitHub Realhaapy입니다. 오류나 누락은 정정 접수 게시판에 해당 기록 주소와 근거를 남겨 주세요. 접수 내용은 공개됩니다.

방문 비교 기능은 이 브라우저의 이전 브리핑 시각만 저장합니다. 계정과 기기 간 추적은 사용하지 않습니다.
