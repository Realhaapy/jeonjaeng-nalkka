먼저 읽히는 것

모든 화면에서 같은 순서로 정보를 찾을 수 있게 합니다.

  1. 관측을 먼저. 최근 기록, 달라진 점, 공식 자료의 확인 범위를 첫 화면에 둡니다.
  2. 근거까지 한 번 더. 사건 제목에서 사실·해석·미확인 내용과 원문으로 이어집니다.
  3. 상세는 필요할 때. 지도는 첫 화면에서 바로 보고, 분야·그래프·원문 목록은 펼쳐서 읽습니다.
  4. 숫자의 뜻을 곁에. 등록 건수는 전쟁 확률이나 안전 판정이 아닙니다. 0건도 실제 사건이 없다는 뜻이 아닙니다.

모바일과 접근성

작은 화면에서는 글자를 줄이지 않고 배치를 바꿉니다.

  • 데스크톱에서는 요약 옆에 지도를 둡니다. 1000px 이하는 요약 다음에 지도를 세로로 배치하고, 760px 이하는 목록·변경 이력·상세를 한 열로 읽습니다.
  • 버튼과 접기 영역은 높이 44px 이상. 검색창은 48px이며 선택 시 파란 테두리로 초점을 보여 줍니다.
  • 본문·보조 글자는 배경과 4.5:1 이상의 대비를 목표로 검증합니다. 색상만으로 상태를 구분하지 않습니다.
  • 기본 애니메이션은 상태 전환 150ms 이내. 기기에서 동작 줄이기를 켜면 전환 효과를 끕니다.
  • 본문 바로가기, 제목 순서, 입력 이름, 펼침 상태를 제공하고 자바스크립트 없이도 기록을 읽을 수 있게 합니다.
  • 보존본은 생성 당시 화면 자산을 유지합니다. 디자인 기준은 현재 공개 화면의 공통 스타일과 함께 갱신합니다.
